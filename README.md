# 양현웅 포트폴리오

웹디자이너 & 퍼블리셔 양현웅의 작업을 소개합니다. 업데이트: 2026.10.06.

[포트폴리오 보기](https://angrieta.github.io/portfoilo_yhw/)

## 구성

- 자연스러운 문서 스크롤과 About / Web / Graphic / Contact 탐색. 소개 다음에 경력을 먼저 배치합니다.
- 이름과 역할, 대표 작업 화면이 함께 보이는 소개 영역. 작업 화면에서 해당 프로젝트로 바로 이동합니다.
- 10개 웹 프로젝트를 개별 선택하고 실제 구현 페이지를 iframe으로 표시합니다.
- 공통 동작: 사이트 열기, 데스크톱·모바일 미리보기, 확대, 처음으로, 작업 설명, Figma.
- 전후 비교 이미지는 회사 작업 설명의 보조 자료로 유지합니다.
- 그래픽 47건: 실무 14건 + 기존 상세페이지 10건, SNS 8건, 배너 15건.
- 그래픽 분류, 더 보기, 원본 확대, 키보드 닫기와 포커스 복귀를 지원합니다.
- 경력, 교육, 도구, 연락처를 별도 영역에 정리했습니다.

회사 시연본은 운영 서버를 복제한 서비스가 아니라 디자인·퍼블리싱 결과를 확인하는 UI 데모입니다.
실제 상담 접수는 차단하며, 상품 데이터는 고정 예시입니다. 카베이의 고객 후기 역시 익명 예시로 교체했습니다.
카베이 후기·매니저 사진은 원본 UI의 공개 이미지로 복원했고, 인기 차량과 매니저는 각각 5개를 표시합니다.
카프로 배너 3개, 차량 선택창 사진 26개, 후기 사진 12개를 시연본 내부에 보관합니다.
정적 호스팅에서 동작하지 않는 이미지 최적화 서버 경로 대신 실제 이미지 파일을 사용합니다.
쇼츠와 일반 영상은 카베이 공식 YouTube 공개 영상으로 연결합니다. 썸네일은 시연본에 보관하며,
영상 재생에는 인터넷 연결이 필요합니다. 외부 플레이어를 차단하는 환경을 위해 YouTube 직접 링크도 제공합니다.
미디어 출처는 `demos/carbay/media/sources.json`, `demos/carpro/media/sources.json`에 기록했습니다.
전자명함은 첨부 원본의 모바일 중심 화면을 그대로 표시합니다. 원본의 미리보기 모드를 유지하여 상담 폼은 실제 전송하지 않습니다.
운영 서버가 필요한 일부 메뉴는 시연 범위를 안내합니다. 회사 소스 원본과 개인 ZIP 원본은 수정하지 않았습니다.
회사 프로젝트의 전후 비교 이미지는 이전 기록이며, 웹 미리보기가 현재 시연 소스입니다.

## 실행과 배포

GitHub Pages는 `landing` 브랜치 루트를 배포합니다. `.nojekyll`은 Next 정적 파일의 `_next` 경로에 필요합니다.
메인 포트폴리오에는 별도 빌드가 필요하지 않습니다. `demos/carbay`, `demos/carpro`는 이미 빌드한 정적 결과물입니다.
시연본의 자산 경로는 `/portfoilo_yhw/` 기준입니다. 로컬 확인 시 HTTP 서버에서 동일 경로로 제공해야 합니다.
외부 웹사이트·Figma·시연본의 외부 이미지와 일부 라이브러리는 인터넷 연결이 필요합니다.

## 수정 위치

- `index.html`: 소개, 경력, 연락처, 섹션 구조.
- `styles/portfolio-ux.css`: 현재 화면의 전체 스타일.
- `scripts/portfolio-ux.js`: 프로젝트 선택, 실제 미리보기, 갤러리, 상세창.
- `scripts/projects.js`: 프로젝트 설명·비교 기록·기존 작업 목록.
- `scripts/creative-data.js`: 그래픽 작업 설명·분류·출처.
- `demos/`: 공개용 시연 사이트. `demo-guard.js`는 실제 상담 접수를 차단합니다.
- `images/work`, `images/creative`, `images/thumbs`, `images/original_image`: 작업 이미지.

기존 Swiper 기반 UI 파일은 이전 기록으로 남아 있으나 현재 메인 페이지에서 로드하지 않습니다.

## 작업 구분

- 카베이 입사: 2025.09.01, 현재 재직 중. 세 서비스의 UI 디자인·퍼블리싱 전담.
- DB 접수 20% 이상 증가는 작성자가 제공한 전체 사이트 개선 이후 성과이며 개별 사이트 전환율이 아닙니다.
- CARMONG은 회사와 별개의 개인 작업입니다. 시안에 표시된 수치는 작성자의 업무 성과가 아닙니다.
- CARPRO 로고는 브랜드 자산 활용 작업으로 구분합니다. 타사 참고 로고·캐릭터는 갤러리에서 제외했습니다.
- 전자명함의 인물 정보는 첨부 원본 내용이며, 실적 수치는 해당 시안 기준입니다.
