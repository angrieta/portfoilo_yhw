# 양현웅 포트폴리오

웹디자이너 & 퍼블리셔 양현웅의 작업을 소개합니다. 업데이트: 2026.10.01.

[포트폴리오 보기](https://angrieta.github.io/portfoilo_yhw/)

## 실행과 배포

`index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드가 필요 없는 정적 사이트입니다.
글꼴, 이미지, 사용 중인 라이브러리를 자체 포함하며 외부 사이트와 Figma 링크를 열 때 인터넷 연결이 필요합니다.
GitHub Pages는 `landing` 브랜치의 루트 폴더를 배포합니다.

## 구성

- 원래의 민트색, 영문 타이포그래피, 원형 장식과 전체 화면 슬라이드 구성을 유지합니다.
- Intro / Profile / Web project / Brand & Graphic / Design project / Design sns / Design banner / End.
- 웹 프로젝트 9건: 카베이, 카프로, 차나와, CARMONG, 베베드피노, 타임클리닉, M-mall, NuPhy, 크라이저.
- 모든 웹 프로젝트에 공통 레이아웃과 '프로젝트 보기' 상세창을 적용했습니다. 기존 사이트·Figma·구현 화면 링크는 상세창에 보존했습니다.
- 회사 프로젝트 3건은 실제 저장 화면으로 전후 비교가 가능합니다. CARMONG은 개인 디자인 시안 #3·#4의 네 화면을 제공합니다.
- Brand & Graphic 17건: 배너 9, 상세페이지 2, 팝업 2, 로고·브랜딩 2, UI 시안 2.
- 기존 상세페이지 10건, SNS 8건, 배너 15건도 유지합니다.
- 이미지 확대, 작업별 이동, 모바일 섹션 메뉴, 키보드 접근과 동작 줄이기를 지원합니다.

## 내용 수정

- `index.html`: 원래 페이지, 기존 프로젝트 원본 정보, 프로필과 연락처.
- `scripts/projects.js`: 최근 웹 프로젝트 설명과 비교 이미지, 링크.
- `scripts/additions.js`: 9개 프로젝트의 공통 레이아웃과 상세창.
- `scripts/creative.js`: 새 그래픽 작업 17건의 분류, 제목, 설명, Figma 출처.
- `styles/projects.css`, `styles/creative.css`: 해당 두 영역의 디자인.
- `styles/additions.css`: 프로필, 상세창, 자체 글꼴과 모바일 메뉴.
- `scripts/swiper.js`, `scripts/index.js`: 슬라이드와 탐색, 기존 이미지 팝업.
- `images/work/`: 실제 웹 프로젝트 저장 화면.
- `images/creative/`: 새 그래픽 작업의 전체 이미지와 미리보기.
- `images/thumbs/`: 기존 갤러리용 가벼운 미리보기. 확대 시 원본을 사용합니다.

## 작업 구분

- 카베이 웹디자이너, 2025.09.01 입사 후 현재 재직 중.
- 카베이·카프로·차나와의 UI 디자인 및 퍼블리싱 전담은 작성자 확인 내용입니다.
- DB 접수 20% 이상 증가는 작성자가 제공한 재직 중 사이트 개선 후 전체 성과입니다. 개별 사이트의 증가율이나 전환율로 표시하지 않습니다.
- 카베이 변경 후 화면은 최신 로컬 리뉴얼 소스를 기준으로 합니다. 공개 운영 화면을 대체 자료로 사용하지 않았습니다.
- 차나와 변경 후 화면은 개발 작업본입니다. 내부 서버 주소 대신 저장 이미지를 제공합니다.
- CARMONG은 회사와 별개인 개인 작업입니다. 시안 속 상품·이용 수치를 업무 성과로 사용하지 않습니다.
- 전자명함 속 인물 정보와 수치는 UI 시안에 포함된 예시이며, 포트폴리오 작성자의 성과가 아닙니다.
- Figma의 명확한 타사 참고 로고·캐릭터와 내부 피드백 자료는 갤러리에서 제외했습니다.
- CARPRO 로고는 브랜드 자산 활용 작업으로 구분하며, 별도의 로고 원천 창작 실적을 주장하지 않습니다.
- 외부 사이트의 현재 내용이나 Figma 접근 권한은 해당 서비스 설정에 따라 달라질 수 있습니다.

## 확인
