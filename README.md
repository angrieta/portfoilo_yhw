# 양현웅 포트폴리오

웹디자이너 & 퍼블리셔 양현웅의 작업을 소개합니다. 업데이트: 2026.10.20.

[포트폴리오 보기](https://angrieta.github.io/portfoilo_yhw/)

## 구성

- 자연스러운 문서 스크롤과 Web / Graphic / About / Contact 탐색. 소개 → 웹 작업 → 그래픽 → 경력·역량 → 연락처 순서입니다.
- 첫 대표작은 카베이, 투썸플레이스, 브랜드 레퍼런스입니다. 실무 개선·브랜드 디자인·웹 도구 구현을 각각 보여줍니다.
- 15개 프로젝트 묶음, 16개 구현·시안 화면을 제공합니다. 대표작 6개를 먼저 보여주고 회사 추가 작업·개인 추가 작업·이전 작업은 펼쳐서 탐색합니다.
- 롤렉스는 한 묶음 안에서 컬렉션 탐색형 웹사이트와 제품 집중형 UI 시안으로 전환합니다. 기존 `?project=rolex`와 `?project=rolex-web` 링크는 유지합니다.
- 공통 동작: 사이트 열기, 데스크톱·모바일 미리보기, 확대, 처음으로, 작업 과정, Figma. 공개 개인 작업에는 구현 코드 링크도 제공합니다.
- 대표작 6개의 작업 과정에는 담당 범위, 디자인 결정, 실제 화면과 구현 사례를 정리했습니다. 카베이는 메뉴 클릭 자료, 전자명함은 작은 UI 가이드를 포함합니다. 모루는 어순 설명과 답안별 피드백을 PC·모바일 화면으로 보여줍니다.
- 전후 비교 이미지는 회사 작업 설명의 보조 자료로 유지합니다.
- 그래픽 47건: 실무 14건 + 기존 상세페이지 10건, SNS 8건, 배너 15건.
- 그래픽 8건을 먼저 선별해 보여줍니다. 가로 배너·상세페이지·SNS의 비율을 구분하고, 기존 33개 작업에도 내용에 맞는 제목과 설명을 붙였습니다.
- 그래픽 분류, 더 보기, 원본 확대, 한가위 배너·상세 캠페인, 키보드 닫기와 포커스 복귀를 지원합니다.
- 경력, 교육, 도구, 연락처를 별도 영역에 정리했습니다.

회사 시연본은 운영 서버를 복제한 서비스가 아니라 디자인·퍼블리싱 결과를 확인하는 UI 데모입니다.
실제 상담 접수는 차단하며, 상품 데이터는 고정 예시입니다. 카베이의 고객 후기 역시 익명 예시로 교체했습니다.
카베이 후기·매니저 사진은 원본 UI의 공개 이미지로 복원했고, 인기 차량과 매니저는 각각 5개를 표시합니다.
카프로 배너 3개, 차량 선택창 사진 26개, 후기 사진 12개를 시연본 내부에 보관합니다.
정적 호스팅에서 동작하지 않는 이미지 최적화 서버 경로 대신 실제 이미지 파일을 사용합니다.
쇼츠와 일반 영상은 카베이 공식 YouTube 공개 영상으로 연결합니다. 썸네일은 시연본에 보관하며,
영상 재생에는 인터넷 연결이 필요합니다. 외부 플레이어를 차단하는 환경을 위해 YouTube 직접 링크도 제공합니다.
미디어 출처는 `demos/carbay/media/sources.json`, `demos/carpro/media/sources.json`에 기록했습니다.
전자명함은 첨부 원본의 모바일 중심 화면을 그대로 표시합니다. 원본의 미리보기 모드를 유지하여 상담 폼은 실제 전송하지 않습니다.
운영 서버가 필요한 일부 메뉴는 시연 범위를 안내합니다. 회사 소스 원본과 개인 ZIP 원본은 수정하지 않았습니다.
회사 프로젝트의 전후 비교 이미지는 이전 기록이며, 웹 미리보기가 현재 시연 소스입니다.

커피 브랜드 작업은 `demos/coffee/`에 이미지·폰트·스크립트를 함께 보관하며, 스타벅스와 투썸플레이스를 독립 프로젝트로 표시합니다. 외부 로그인 없이 미리 볼 수 있고, 각 항목에 작업 설명과 Figma 디자인 파일을 연결했습니다. 이미지 출처는 `demos/coffee/asset-sources.json`에 기록되어 있습니다.

모루는 [별도 공개 사이트](https://angrieta.github.io/moru-vocabulary/)를 그대로 미리 보여주며 음성·단어 데이터를 이 저장소에 중복 보관하지 않습니다. `?project=moru#web-project`로 바로 선택할 수 있습니다. 학습 기록은 브라우저에 저장되므로 실제 사용 중인 기록을 유지하고, 채점 확인은 로컬 테스트 환경에서 진행합니다. 작업 과정의 화면은 2026.10.20 구현본이며 모바일 오답 화면은 테스트용 답안입니다.

## 실행과 배포

GitHub Pages는 `landing` 브랜치 루트를 배포합니다. `.nojekyll`은 Next 정적 파일의 `_next` 경로에 필요합니다.
메인 포트폴리오에는 별도 빌드가 필요하지 않습니다. `demos/carbay`, `demos/carpro`는 이미 빌드한 정적 결과물입니다.
시연본의 자산 경로는 `/portfoilo_yhw/` 기준입니다. 로컬 확인 시 HTTP 서버에서 동일 경로로 제공해야 합니다.
외부 웹사이트·Figma·시연본의 외부 이미지와 일부 라이브러리는 인터넷 연결이 필요합니다.

## 수정 위치

- `index.html`: 소개, 경력, 연락처, 섹션 구조.
- `styles/portfolio-ux.css`: 기존 화면의 공통 스타일.
- `styles/portfolio-refinement.css`: 대표작 위계, 가독성, 작업 과정과 데이터 시각화, 반응형 개선.
- `scripts/portfolio-ux.js`: 프로젝트 선택, 실제 미리보기, 갤러리, 상세창.
- `scripts/projects.js`: 프로젝트 설명·비교 기록·기존 작업 목록.
- `scripts/creative-data.js`: 그래픽 작업 설명·분류·출처.
- `scripts/case-studies.js`: 대표작 사례, 제공된 클릭 집계와 아카이브 제목.
- `demos/`: 공개용 시연 사이트. `demo-guard.js`는 실제 상담 접수를 차단합니다.
- `images/work`, `images/creative`, `images/thumbs`, `images/original_image`: 작업 이미지.

대표작 슬라이더는 `scripts/featured-work.js`와 Swiper를 사용합니다. 자동 재생은 하지 않으며, 키보드 전환·비활성 슬라이드의 포커스 제외·동작 줄이기 설정을 지원합니다.

검수 환경과 수정 근거는 [2026.10.19 검수 기록](docs/portfolio-review-20261019.md)에 정리했습니다.

## 작업 구분

- 카베이 입사: 2025.09.01, 현재 재직 중. 세 서비스의 UI 디자인·퍼블리싱 전담.
- 제공된 메뉴 클릭 집계표의 합계는 4,181회이며, 전차종 견적·즉시출고·렌트VS리스는 3,600회(86.1%)입니다. 표에 기간과 이전 수치가 없어, 이전의 DB 증가율 문구를 이 자료로 검증할 수 없습니다. 공개 화면에는 확인 가능한 클릭 현황을 표시합니다.
- 회사 작업의 재직 기간과 실제 제작 기간을 구분합니다. 확인되지 않은 제작 기간, 협업 분담, 이력서 주소를 추정해 추가하지 않았습니다.
- CARMONG은 회사와 별개의 개인 작업입니다. 시안에 표시된 수치는 작성자의 업무 성과가 아닙니다.
- CARPRO 로고는 브랜드 자산 활용 작업으로 구분합니다. 타사 참고 로고·캐릭터는 갤러리에서 제외했습니다.
- 전자명함의 인물 정보는 첨부 원본 내용이며, 실적 수치는 해당 시안 기준입니다.
